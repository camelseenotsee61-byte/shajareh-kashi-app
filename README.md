# شجره‌نامه خاندان کاشی حسینی 🌳

اپلیکیشن رسمی درخت خانوادهٔ خاندان کاشی حسینی

## اهداف برنامه:
- حفظ و انتقال شجره‌نامه به نسل‌های آینده
- تقویت پیوندهای خانوادگی و همدلی
- دست‌گیری از نیازمندان خانواده با حفظ آبرو
- آلبوم خاطرات و دل‌نوشته‌های اعضا

## تولیدکننده:
**حمید حسینی** (مدیر کل برنامه)
